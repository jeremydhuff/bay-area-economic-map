## Updating the data

Every update is a full update across the whole site: use the latest quarter as the label (e.g. "2026 Q2", not "H1"), and refresh every part that depends on the data (headline chart and stat tiles, methodology and sources text, footer date, aria-labels, county map). See the update log comment at the top of `index.html` for the series and steps.
